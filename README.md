# 🗃️🛠️ Construção de Bancos de Dados Relacionas
Este repositório foca na modelagem e implementação de bancos de dados relacionais, abordando conceitos como normalização, SQL avançado, otimização de consultas e integração com sistemas backen. O objetivo é capacitar os alunos a projetar estruturas de dados eficientes e escaláveis para aplicações do mundo rea.0

## 📂 Estrutura do Repositório

- **Primeiro_Semestre/Material de Aula*: Contém materiais e recursos utilizados durante o primeiro semestre do curso, incluindo slides, exemplos de código e exercícios prátics.

- **Segundo_Semestre*: Inclui conteúdos abordados no segundo semestre, focando em tópicos avançados de bancos de dados relacionais e sua aplicação prátia.

## 🛠️ Tecnologias Utilizadas

- **PL/SQL*: Linguagem principal utilizada para implementação dos conceitos de bancos de dados relacionis.
